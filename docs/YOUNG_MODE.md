# 어린 시절 모드 (테스트 기능)

영상 편지를 **자녀의 어린 시절 모습과 목소리**로 만든다. 영상 만들기 화면에서 "어린 시절 모습으로 만들기 (테스트)"를 체크하고,
어린 시절 사진을 먼저 만들어 본 뒤 영상을 만든다.

```
[미리] 내 사진 → 어린 시절 사진 한 장 (photo/young.png). 마음에 들지 않으면 다시 만들기 (새 seed)
[영상] 대본 → TTS(내 목소리) → [목소리 어리게] → [그 사진] → FLOAT → 영상
```

| 바꾸는 것 | 방법 | 어디서 |
|---|---|---|
| 목소리 | 목소리 높이를 아이 목소리 높이(`YOUNG_VOICE_HZ`, 270Hz)로 맞추고, 울림(포먼트)은 따로 조금만(1.15배) 올린다. 길이는 그대로 | 백엔드 (Praat Change gender, `audio.make_younger`) |
| 사진 | Qwen-Image-2.1 Turbo(8비트)로 편집. 영상 전에 미리 보여 주고, `photo/young.png`에 두고 다음 영상부터 그대로 쓴다 | GPU PC의 ComfyUI (`services/young.py`) |

### 미리 만들어 보기

- 예전에는 영상을 만들면서 사진도 같이 만들어서, 영상이 다 나온 뒤에야 사진을 볼 수 있었고 다시 만들 방법이 없었다.
- 이제 영상 전에 한 장을 만들어 보여 준다 (워커의 `young_photo` 작업, `worker.run_young_photo`). 약 30초(T4).
- "사진 다시 만들기"는 새 seed로 만든 사진으로 바꾼다. 새 사진에서 얼굴을 찾지 못하면 실패로 보여 주고 지난 사진을 그대로 둔다.
- 후보 여러 장 중에서 고르는 방식도 만들어 봤지만, GPU를 여러 배 쓰고 seed에 따라 결과가 얼마나 달라지는지 재 보지 않아서 한 장으로 줄였다 (2026-11-25).
- 사진을 못 바꾸는 서버(`COMFYUI_URL` 없음)는 만들어 보지 않아도 영상을 만든다 (원본 사진 + 어린 목소리).

| API | 하는 일 |
|---|---|
| `GET /api/photo/young` | 사진 주소, 만드는 중인지, 실패 안내 |
| `POST /api/photo/young` | 만들기·다시 만들기 (얼굴 사진 동의 필요) |
| `GET /api/photo/young/image` | 만든 사진 |

`POST /api/messages/{id}/render`에 `young: true`를 보낼 때 사진을 바꿀 수 있는 서버인데 아직 만들어 보지 않았으면 409로 막는다.

## 테스트 1: GPU 없이 (목소리만)

`COMFYUI_URL`을 비워 두면 사진은 원본을 그대로 쓰고 목소리만 바꾼다.

1. `npm run dev:all`
2. 메시지 화면에서 **어린 시절 모습으로 만들기**를 체크하고 영상 만들기
3. 목소리를 바꿔 보려면 `backend/.env`의 `YOUNG_VOICE_HZ`·`YOUNG_VOICE_FORMANT`·`YOUNG_VOICE_RANGE`를 고치고 워커를 다시 켠 뒤 "다시 만들기"
   - 울림(`YOUNG_VOICE_FORMANT`)을 너무 올리면 헬륨 목소리처럼 들린다

## 테스트 2: GPU PC에서 사진까지

### ComfyUI 준비 (한 번)

1. ComfyUI 설치 (최신 버전이어야 Qwen-Image-2.1 블록이 있다)
   - Windows: [ComfyUI 포터블](https://github.com/comfyanonymous/ComfyUI/releases)을 받거나
   - `git clone https://github.com/comfyanonymous/ComfyUI.git` 후 CUDA용 torch가 있는 가상환경에서 `pip install -r requirements.txt`
2. 모델 파일 3개를 [Comfy-Org/Qwen-Image-2.1](https://huggingface.co/Comfy-Org/Qwen-Image-2.1)에서 받아 넣는다

   | 파일 | 넣을 곳 | 크기 |
   |---|---|---|
   | `diffusion_models/qwen_image_2.1_turbo_int8_convrot.safetensors` | `ComfyUI/models/diffusion_models/` | 6.76GB |
   | `text_encoders/qwen3vl_8b_int8_convrot.safetensors` | `ComfyUI/models/text_encoders/` | 8.71GB |
   | `vae/qwen_image_2.1_vae_bf16.safetensors` | `ComfyUI/models/vae/` | 0.64GB |

3. 실행 (이 PC 안에서만 열기)
   ```
   python main.py --listen 127.0.0.1 --port 8188 --reserve-vram 4
   ```
   - `--reserve-vram 4`: TTS 서버(약 3.2GB)가 쓸 자리를 남긴다. 메모리 부족 오류가 나면 이 값을 조정한다
   - 사진을 다 만들면 백엔드가 `/free`를 불러 ComfyUI 모델을 내린다 (FLOAT가 쓸 자리)

### 백엔드 설정

- 같은 PC에서 백엔드를 돌릴 때: `backend/.env`에 `COMFYUI_URL=http://127.0.0.1:8188`
- Azure 백엔드에서 부를 때: GPU 게이트웨이가 `/comfy`를 ComfyUI로 넘긴다
  ```
  COMFYUI_URL=https://<PC>.<tailnet>.ts.net/comfy
  COMFYUI_API_KEY=<GPU_GATEWAY_TOKEN과 같은 값>
  ```

### 확인

1. 메시지 화면에서 체크하고 **어린 시절 사진 만들어 보기**. T4 기준 약 33초, 모델을 처음 불러올 때는 몇 분 더 걸린다
2. 사진이 나오면 영상 만들기. 사진을 만들기 전에는 영상 만들기 버튼이 꺼져 있다
3. 만든 사진: `backend/data/users/<사용자ID>/photo/young.png`
4. 마음에 들지 않으면 "사진 다시 만들기". 사진을 새로 올리면 만든 사진도 지운다

## 설정

| 변수 | 기본값 | 설명 |
|---|---|---|
| `COMFYUI_URL` | (없음) | 비우면 원본 사진을 쓰고 목소리만 바꾼다 |
| `COMFYUI_API_KEY` | (없음) | 게이트웨이를 거칠 때 토큰 (`X-API-Key`) |
| `YOUNG_AGE` | 6 | 지시문의 나이. 바꿔도 이미 만든 사진은 그대로다 |
| `YOUNG_VOICE_HZ` | 270 | 맞출 목소리 높이(Hz). 원래 목소리와 상관없이 이 높이가 된다. 0이면 목소리는 그대로 |
| `YOUNG_VOICE_FORMANT` | 1.15 | 울림(포먼트) 배율 |
| `YOUNG_VOICE_RANGE` | 1.0 | 억양 폭 배율. 1이면 원래 억양 그대로 (1.3도 들어 봤지만 나아지지 않았다) |

## 실험으로 정한 것 (2026-11-10~11, Kaggle T4, 본인 증명사진 1장)

| 시도 | 시간 | 결과 |
|---|---|---|
| SAM (나이 변환 전용 모델, 2021) | — | 품질이 낮다 |
| Qwen Chat (웹) | — | 12~13살, 닮음 높음. 워터마크가 있고 자동으로 부를 수 없어 비교용 |
| Qwen-Image-Edit-2511, 4비트 + Lightning 4단계 | 327초 | 9~11살이지만 머리·얼굴이 평균적인 아이로 바뀐다 |
| ㄴ Lightning 없이 40단계 | 4,919초 | 4단계와 거의 같다 |
| **Qwen-Image-2.1 Turbo 8비트, 8단계** | **33초** | 아래 지시문에 따라 결과가 갈린다 |
| ㄴ + 공식 지시문 다듬기 모델 | 504초 | 닮음은 가장 높지만 거의 안 어려진다 (15~16살) |
| ㄴ 원래 모델(Turbo 아님) 25단계 / 40단계 | 292초 / 370초 | Turbo와 거의 같다 |

- **단계 수는 결과를 거의 바꾸지 않았고 지시문이 좌우했다.**
- "같은 얼굴형 유지"를 넣으면 거의 안 어려진다. 아이는 얼굴 비율 자체가 달라서다.
- 나이 숫자(7·5·4살)만 바꾸면 13~14살에서 멈췄다. **"같은 옷·같은 구도 유지"** 가 정장과 어른 어깨를 붙잡아 두었기 때문이다.
- 옷을 아이 옷으로 풀고 **"조금 멀리서 찍은 구도(머리를 작게)"** 를 넣자 9~11살로 가장 어려 보였다 (실험의 A2).
- 같은 편집을 두 번 돌리면 피부·머리에 잡티가 쌓여서 더 나빠졌다.
- 지금 지시문(`services/young.py`의 `PROMPT`)은 A2에서 두 군데를 바꿨다: 옷을 특정하지 않고 "원본과 비슷한 아이 옷"으로, 안경은 "쓴 사람만". **이 두 군데는 아직 실제로 돌려 보지 않았다.**

## 알아 둘 점

- **라이선스**: Qwen-Image-2.1은 Qwen Research License라서 **상업적으로 쓰려면 별도 계약**이 필요하다. 출시할 때는 Qwen-Image-Edit-2511(Apache 2.0)이나 유료 API를 다시 검토한다.
- **본인 확인이 없다**: 남의 사진으로 아이 영상을 만들 수 있다. 정식 기능으로 열기 전에 본인 확인과 동의 항목(사진 변환)을 추가해야 한다.
- **ComfyUI에 남는 파일**: 원본 사진이 ComfyUI `input` 폴더에 `ongi_user_<ID>.jpg`로 남는다 (사용자별로 덮어쓴다). 결과는 임시 폴더라 ComfyUI를 다시 켜면 지워진다. 테스트가 끝나면 `input` 폴더를 비운다.
- **목소리 변환은 신호 처리(PSOLA)**라 AI 음성 변환보다는 기계적으로 들릴 수 있다. 목소리 높이를 못 찾는 음성이면 예전 방식(높이·울림을 함께 1.25배)으로 바꾼다.

## 목소리 비교 (2026-11-25, 내 녹음 3개 + Windows Heami 2문장)

예전 방식은 높이와 울림을 같은 배율(1.25)로 올려서, 낮은 목소리는 아이 목소리 높이(대략 250~300Hz)까지 못 올라갔다.
Praat의 Change gender는 목표 높이를 정하면 원래 목소리와 상관없이 그 높이로 맞추고, 울림은 따로 정한다.

| 원래 목소리 | 예전 방식 (1.25배) | 목표 270Hz · 울림 1.15 · 억양 1.3 (N2) |
|---|---|---|
| 내 녹음 117 / 131 / 134Hz | 144 / 160 / 163Hz | 266 / 269 / 268Hz |
| Heami 197 / 204Hz | 245 / 254Hz | 270 / 271Hz |

- 길이는 0초 차이 (예전 방식은 -0.01~-0.02초)
- 억양 폭 1.3은 Heami에서 9.7 → 13.5반음, 11.1 → 15.2반음으로 넓어졌다 (내 녹음은 원본 측정에 음높이 오검출이 섞여서 비교하기 어렵다)
- PSOLA로 이어 붙이면 파형이 한쪽으로 치우쳐서(DC) 변환 뒤에 평균을 뺀다
- 블라인드로 들어 보니 N1(270Hz · 울림 1.15 · 억양 그대로)이 그나마 나았지만, **모든 방식이 찌지직거리고 기계음 같았다**. 그래서 기본값을 N1로 두었다
- 원인: 낮은 목소리는 2배 넘게(약 14반음) 올려야 해서 신호 처리로는 깨끗하게 바꾸기 어렵다. 비교에 쓴 녹음 자체도 잡음이 많았다 (HNR 6~8dB, Heami 17dB)

### WORLD 보코더 비교

PSOLA처럼 파형 조각을 이어 붙이지 않고 분석·재합성하는 WORLD(pyworld)도 비교했다 (W1: 270Hz · 울림 1.15, W2: 240Hz · 울림 1.10).
- 깨끗한 음성(Heami)에서 순간적으로 튀는 소리가 Praat의 절반 이하였다 (초당 149~268 vs 537~538)
- 그런데 들어 보면 Praat N1이 나았다. 튀는 소리 수는 귀로 듣는 품질을 잡지 못했다
- pyworld는 Python 3.14와 Linux용 미리 빌드된 파일이 없어서 쓰려면 빌드 환경이 필요하다

### 다음 시험: TTS가 처음부터 아이 목소리로 말하게 하기

참조 음성을 먼저 어린 목소리로 바꿔 TTS 목소리를 따로 등록하면, TTS가 소리를 새로 만들어서 변환 잡음이 걸러질 수 있다.
GPU PC에서 `experiments/young_voice_tts.py`로 비교한다 (내 목소리 → 나중에 변환 / 아이 목소리 등록 / 등록 + 높이 보정, 블라인드 청취 페이지).
```
.venv\Scripts\python.exe experiments\young_voice_tts.py --user-id <사용자 번호>
```
결과에 따라 앱도 이 방식으로 바꿀지 정한다. 그 전까지 시연은 목소리를 바꾸지 않는 것도 방법이다 (`YOUNG_VOICE_HZ=0`)
- 만든 사진은 조금 멀리서 찍은 구도의 매끈한 아이 얼굴이라 사진 등록 때 쓰는 기본 얼굴 검출기가 놓친다 (실험 결과 A2·A3 둘 다). 그래서 다른 검출기(OpenCV alt2)로 한 번 더 찾고, 둘 다 못 찾을 때만 영상 만들기가 실패로 끝난다. 사진의 흐림·얼굴 크기 검사는 만든 사진에는 적용하지 않는다.
