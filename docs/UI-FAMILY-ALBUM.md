# 가족 앨범 × 온기 클럽 UI

팀 투표 결과에 따라 가족 앨범형 구조와 온기 클럽의 색감을 결합했습니다. 최신 main `abd55f5`를 바탕으로 작업했으며, 기존 다섯 가지 비교용 작업 폴더는 수정하지 않았습니다.

## 구성

- 크림 배경 `#fffaf4`, 토마토 포인트 `#c8493c`, 살구 `#fae8de`, 버터 옐로 `#fff0bd`, 브라운 글씨 `#493035`.
- 가로 메뉴, 테이프로 붙인 가족 일러스트 표지, 가족·월별 편지 카드, 펼친 편지지 형태의 작성 화면.
- 기존 family-together / son-character / daughter-character 이미지를 유지합니다. 실제 영상 포스터가 있으면 해당 포스터를 표시합니다.
- 로그인, 가족 편지함, 대화·월간 포트폴리오, 목소리·사진 준비, 설정, 가족 수신 화면에도 색감을 적용했습니다.

## 실제 화면과 프리뷰

실제 `/home`은 기존 인증과 API를 그대로 사용합니다. 사용자 편지가 없으면 빈 앨범을 표시하며, 샘플 기록을 실제 계정에 넣지 않습니다. 가족별·월별 필터는 불러온 실제 편지 목록에 적용합니다. 기존 백엔드, API 프록시, src/lib, shared 데이터에는 변경이 없습니다.

`/dev-preview`는 개발 모드 전용이며 로그인 없이 디자인을 확인할 수 있습니다. 가족 관리, 편지 작성, 준비, 생성 상태·재시도, 승인·공유, 수신·답글, 날짜·월별 기록, 알림, 설정을 브라우저 메모리에서 체험합니다. 새로고침하면 초기화됩니다. 실제 마이크·AI 생성·발송·계정 변경은 실행하지 않습니다. 영상은 기존 캐릭터 이미지와 샘플 자막으로 표시하고, 다운로드는 샘플 대본 파일입니다.

최신 기능인 한 문장 기본 목소리 등록, 선택형 135초 목소리 다듬기, 어린 시절 모드도 유지했습니다. 프리뷰에서 어린 시절 옵션은 선택 상태만 체험하며 이미지 변환은 수행하지 않습니다. 실제 영상 생성 요청에는 기존 `emotion`, `young` 값이 전달됩니다.

## 실행

이 데스크탑에서는 상위 작업 폴더의 `start-previews.ps1 -Port 3000`으로 서버 하나만 실행합니다. 주소는 `http://localhost:3000/dev-preview`입니다. 일반 환경에서는 Node.js 설치 후 이 체크아웃에서 `npm ci`, `npm run dev`로 실행합니다. 실제 화면은 백엔드와 유효한 로그인 세션이 필요합니다.

## 검증

- `npm run build` 성공: 프로덕션 빌드와 타입 검사.
- 변경한 실제 프론트엔드 23개 파일의 API 호출 34개를 TypeScript AST로 이전 버전과 비교: 호출 경로와 요청 인자 동일.
- 크롬 프리뷰 1440px / 390px: 가족 CRUD, 동의, 기본 목소리·선택형 다듬기·사진, 작성·옵션, 생성·재시도, 승인·공유·대본 다운로드, 수신·답글, 날짜·월별 기록, 알림, 설정·동의 철회, 회원가입 체험 통과. 자바스크립트 오류·가로 넘침·실제 API 요청 없음.
- 실제 프론트엔드 1440px / 768px / 390px: 브라우저 네트워크 테스트 응답으로 앨범·필터·빈 상태, 작성 요청, young 렌더 요청, 기본 목소리·선택형 학습, 가족·대화·월간·설정, 401 로그인 이동 확인. 자바스크립트 오류·가로 넘침 없음.
- 실제 백엔드·마이크 녹음·AI 영상 생성·외부 공유는 이 UI 작업에서 실행하지 않았습니다.

검증 스크립트와 화면 캡처는 상위 작업 폴더 `.tools/browser/qa-album*.cjs`, `.tools/browser/check-album-contracts.cjs`, `design-previews/album-club/`에 있습니다. 실제 화면 캡처의 계정과 편지는 테스트 응답입니다.
