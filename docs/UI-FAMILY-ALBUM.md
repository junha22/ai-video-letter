## 실제 화면과 프리뷰

실제 `/home`은 기존 인증과 API를 그대로 사용합니다. 사용자 편지가 없으면 빈 앨범을 표시하며, 샘플 기록을 실제 계정에 넣지 않습니다. 가족별·월별 필터는 불러온 실제 편지 목록에 적용합니다. 최초 UI 작업에서는 기존 백엔드, API 프록시, src/lib, shared 데이터를 변경하지 않았습니다. 이후 추가한 앨범 표지 API는 아래 별도 항목에 설명합니다.

`/dev-preview`는 개발 모드 전용이며 로그인 없이 디자인을 확인할 수 있습니다. 가족 관리, 편지 작성, 준비, 생성 상태·재시도, 승인·공유, 수신·답글, 날짜·월별 기록, 알림, 설정을 브라우저 메모리에서 체험합니다. 새로고침하면 초기화됩니다. 실제 마이크·AI 생성·발송·계정 변경은 실행하지 않습니다. 영상은 기존 캐릭터 이미지와 샘플 자막으로 표시하고, 다운로드는 샘플 대본 파일입니다.

최신 기능인 한 문장 기본 목소리 등록, 선택형 135초 목소리 다듬기, 어린 시절 모드도 유지했습니다. 프리뷰에서 어린 시절 옵션은 선택 상태만 체험하며 이미지 변환은 수행하지 않습니다. 실제 영상 생성 요청에는 기존 `emotion`, `young` 값이 전달됩니다.

## 실행

이 데스크탑에서는 상위 작업 폴더의 `start-previews.ps1 -Port 3000`으로 서버 하나만 실행합니다. 주소는 `http://localhost:3000/dev-preview`입니다. 일반 환경에서는 Node.js 설치 후 이 체크아웃에서 `npm ci`, `npm run dev`로 실행합니다. 실제 화면은 백엔드와 유효한 로그인 세션이 필요합니다.

## 원하는 이미지로 앨범 표지 바꾸기

홈의 가족 앨범 표지 아래 **표지 바꾸기**에서 JPG·PNG·WebP(15MB 이하)를 고르면 표지가 저장됩니다. **기본 표지로**는 업로드한 파일을 삭제하고 기존 가족 일러스트로 돌아갑니다. 업로드한 이미지는 비율을 유지해 표시합니다. 오류가 발생하면 마지막으로 저장한 표지를 유지합니다.

- 실제 서비스: 로그인한 사용자 계정당 한 개의 표지를 저장하며, 새로고침·재접속 후에도 유지합니다. 가족별 프로필 사진이나 각 영상 편지의 포스터를 변경하는 기능은 아닙니다.
- 개발 프리뷰: 같은 조작을 브라우저 메모리에서 체험합니다. 화면 이동 중에는 유지하고, 새로고침이나 샘플 동의 철회 시 초기화합니다. 서버에 사진을 전송하지 않습니다.
- 사진은 영상 제작용 얼굴 사진과 별도로 저장하며 AI 처리나 얼굴 인식에 사용하지 않습니다.

### API·저장

`GET /api/album-cover`: 저장한 표지 정보 또는 null. `POST /api/album-cover`: multipart `file` 업로드. `GET /api/album-cover/image?v=...`: 해당 계정의 저장 이미지. `DELETE /api/album-cover`: 표지 삭제·기본 표지 복원.

새 `album_covers` 테이블은 기존 `init_db()`가 생성하므로 기존 데이터 교체가 필요하지 않습니다. 파일은 사용자별 `album-cover` 폴더에 저장합니다. 교체 시 이전 파일을 삭제하고, DB 저장 실패 시 새 파일을 제거합니다. 동의 철회 시 표지 행과 파일도 삭제합니다. 사용자 인증·기존 Origin 검사를 적용하며, 표지 이미지는 private/no-store로 응답하고 다른 계정이나 공개 시청 링크에 노출하지 않습니다.

이미지는 실제 디코딩 결과를 확인하고 EXIF 회전 처리 후 긴 변 2048px 이내의 JPEG로 저장합니다. 원본 파일명·위치 등 EXIF 메타데이터는 보관하지 않습니다. 4천만 화소 초과, 손상된 이미지, SVG·움직이는 이미지 등 미지원 형식은 거부하고 기존 표지를 유지합니다.
